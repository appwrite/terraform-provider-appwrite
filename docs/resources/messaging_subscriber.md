# Resource: appwrite_messaging_subscriber

Manages a subscriber to an Appwrite messaging topic.

## Example Usage

```terraform
resource "appwrite_messaging_topic" "announcements" {
  name = "announcements"
}

resource "appwrite_user_target" "jane_newsletter" {
  user_id       = appwrite_auth_user.jane.id
  provider_type = "email"
  identifier    = "jane.newsletter@example.com"
}

resource "appwrite_messaging_subscriber" "jane_newsletter" {
  topic_id  = appwrite_messaging_topic.announcements.id
  target_id = appwrite_user_target.jane_newsletter.id
}
```

## Schema

### Required

- `target_id` (String) The ID of the target to subscribe: an appwrite_user_target, or a target Appwrite created for a user's email address or phone number. Changing this forces a new resource to be created.
- `topic_id` (String) The topic ID to subscribe to. Changing this forces a new resource to be created.

### Optional

- `id` (String) The subscriber ID. Changing this forces a new resource to be created.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.

### Read-Only

- `created_at` (String) The subscriber creation timestamp in ISO 8601 format.
- `updated_at` (String) The subscriber last update timestamp in ISO 8601 format.
