# Resource: appwrite_project_key

Manages an Appwrite project API key.

~> **Note:** Creating project API keys requires an organization-scoped or console administrator credential. A standard project API key cannot create another project API key.

~> **Warning:** The key secret is stored in Terraform state. Use an encrypted remote state backend and restrict access to it.

## Example Usage

```terraform
resource "appwrite_project_key" "deployments" {
  id              = "deployments"
  project_id      = "project-id"
  organization_id = "organization-id"
  name            = "Deployment automation"
  scopes          = ["functions.read", "functions.write", "sites.read", "sites.write"]
}

output "deployment_api_key" {
  value     = appwrite_project_key.deployments.secret
  sensitive = true
}
```

## Schema

### Required

- `name` (String) The API key name.
- `scopes` (Set of String) The permission scopes granted to the API key. A maximum of 100 scopes is allowed.

### Optional

- `expire` (String) The expiration timestamp in ISO 8601 format. Omit for no expiration.
- `id` (String) The API key ID.
- `organization_id` (String) The Appwrite organization ID. Defaults to the provider-level organization_id.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.

### Read-Only

- `accessed_at` (String) The most recent access timestamp in ISO 8601 format.
- `created_at` (String) The API key creation timestamp in ISO 8601 format.
- `sdks` (Set of String) The SDKs that have used this API key.
- `secret` (String, Sensitive) The API key secret.
- `updated_at` (String) The API key last update timestamp in ISO 8601 format.

## Import

Using `terraform import` with an organization, project, and key ID:

```shell
terraform import appwrite_project_key.example organization-id/project-id/deployments
```

When `organization_id` is configured on the provider, use the project and key ID. When both `organization_id` and `project_id` are configured, use the key ID alone:

```shell
terraform import appwrite_project_key.example project-id/deployments
terraform import appwrite_project_key.example deployments
```

Using an import block (Terraform v1.5.0+):

```hcl
import {
  to = appwrite_project_key.example
  id = "organization-id/project-id/deployments"
}
```

The API may not return an existing key's secret during import. Replace the key to generate a new secret when necessary.
