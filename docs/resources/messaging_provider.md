# Resource: appwrite_messaging_provider

Manages an Appwrite messaging provider.

## Example Usage

```terraform
resource "appwrite_messaging_provider" "sendgrid" {
  name       = "sendgrid"
  type       = "sendgrid"
  api_key    = var.sendgrid_api_key
  from_email = "noreply@example.com"
  from_name  = "my app"
}

resource "appwrite_messaging_provider" "smtp" {
  name       = "smtp"
  type       = "smtp"
  host       = "smtp.example.com"
  port       = 587
  username   = "user@example.com"
  password   = var.smtp_password
  encryption = "tls"
  from_email = "noreply@example.com"
}

resource "appwrite_messaging_provider" "twilio" {
  name        = "twilio"
  type        = "twilio"
  account_sid = var.twilio_account_sid
  auth_token  = var.twilio_auth_token
  from        = "+1234567890"
}

resource "appwrite_messaging_provider" "fcm" {
  name                 = "fcm"
  type                 = "fcm"
  service_account_json = file("firebase-service-account.json")
}

resource "appwrite_messaging_provider" "ses" {
  name       = "ses"
  type       = "ses"
  access_key = var.aws_access_key_id
  secret_key = var.aws_secret_access_key
  region     = "us-east-1"
  from_email = "noreply@example.com"
  from_name  = "my app"
}

# Push messages delivered over Appwrite's own MQTT broker. Needs Appwrite 2.3.0
# or later.
resource "appwrite_messaging_provider" "appwrite" {
  name   = "appwrite push"
  type   = "appwrite"
  qos    = 1
  expiry = 86400
}
```

## Provider types

Each `type` takes its own arguments; the description of each argument names the
types it applies to. `access_key`, `secret_key` and `region` are accepted only
with `type = "ses"`, and `qos` and `expiry` only with `type = "appwrite"`.

Credentials are never read back from Appwrite, so a credential changed outside
Terraform is not detected, and an imported provider has none in state until the
configuration sets them. `qos` and `expiry` are read back, and removing either
from the configuration clears it on the server.

The `appwrite` type delivers push messages to clients connected to Appwrite's
own MQTT broker, rather than through APNs or FCM. It needs Appwrite 2.3.0 or later; on an older server,
creating one fails with an error saying so.

## Schema

### Required

- `name` (String) The provider name.
- `type` (String) The provider type. One of: sendgrid, mailgun, smtp, resend, ses, twilio, vonage, msg91, telesign, textmagic, apns, fcm, appwrite. The appwrite type needs Appwrite 2.3.0 or later. Changing this forces a new resource to be created.

### Optional

- `access_key` (String, Sensitive) AWS access key ID. Applies to ses type.
- `account_sid` (String) Twilio account SID. Applies to twilio type.
- `api_key` (String, Sensitive) API key. Applies to sendgrid, mailgun, resend, vonage, telesign, textmagic types.
- `api_secret` (String, Sensitive) API secret. Applies to vonage type.
- `auth_key` (String, Sensitive) APNS auth key content. Applies to apns type.
- `auth_key_id` (String) APNS auth key ID. Applies to apns type.
- `auth_token` (String, Sensitive) Twilio auth token. Applies to twilio type.
- `auto_tls` (Boolean) SMTP auto TLS. Applies to smtp type.
- `bundle_id` (String) iOS bundle ID. Applies to apns type.
- `customer_id` (String) Telesign customer ID. Applies to telesign type.
- `domain` (String) Mailgun domain. Applies to mailgun type.
- `enabled` (Boolean) Whether the provider is enabled.
- `encryption` (String) SMTP encryption: none, ssl, tls. Applies to smtp type.
- `expiry` (Number) Default number of seconds a message is kept for offline delivery, at most 604800 (7 days). Applies to topics with no expiry of their own; the lowest value across a project's enabled appwrite providers wins. Applies to appwrite type.
- `from` (String) Sender phone number or ID. Applies to SMS providers.
- `from_email` (String) Sender email address. Applies to email providers.
- `from_name` (String) Sender name. Applies to email providers.
- `host` (String) SMTP host. Required for smtp type.
- `id` (String) The provider ID. Changing this forces a new resource to be created.
- `is_eu_region` (Boolean) Whether to use EU region. Applies to mailgun type.
- `password` (String, Sensitive) Password. Applies to smtp type.
- `port` (Number) SMTP port. Applies to smtp type.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.
- `qos` (Number) Default MQTT QoS, 0 or 1, for topics on this provider. Unset lets each subscriber choose. Applies to appwrite type.
- `region` (String) AWS region, for example us-east-1. Applies to ses type.
- `reply_to_email` (String) Reply-to email address. Applies to email providers.
- `reply_to_name` (String) Reply-to name. Applies to email providers.
- `sandbox` (Boolean) Use APNS sandbox environment. Applies to apns type.
- `secret_key` (String, Sensitive) AWS secret access key. Applies to ses type.
- `sender_id` (String) Msg91 sender ID. Applies to msg91 type.
- `service_account_json` (String, Sensitive) Firebase service account JSON. Applies to fcm type.
- `team_id` (String) Apple team ID. Applies to apns type.
- `template_id` (String) Msg91 template ID. Applies to msg91 type.
- `username` (String) Username. Applies to smtp and textmagic types.

### Read-Only

- `created_at` (String) The provider creation timestamp in ISO 8601 format.
- `updated_at` (String) The provider last update timestamp in ISO 8601 format.

## Import

Import is supported using the following syntax:

```shell
terraform import appwrite_messaging_provider.sendgrid <provider-id>
```
