# Resource: appwrite_postgresql_branch

Creates a branch of a dedicated Appwrite PostgreSQL database: a copy that shares the parent's credentials but has its own host and database name.

Branches have no update route, so changing any argument replaces the branch and discards its data. A branch given a `ttl` is deleted by the server when it expires; the next refresh then drops it from state and the following plan recreates it.

## Example Usage

```terraform
resource "appwrite_postgresql_database" "main" {
  name          = "main"
  specification = "db-s-1vcpu-1gb"
}

# A branch is a copy of the parent that shares its credentials but has its own
# host and database name. Useful for giving a preview environment real data
# without pointing it at production.
resource "appwrite_postgresql_branch" "preview" {
  database_id = appwrite_postgresql_database.main.id
  branch_id   = "preview"
}

# A branch with a TTL is deleted by the server when it expires. Terraform drops
# it from state on the next refresh and recreates it on the following apply, so
# expect a short-lived branch to come back rather than stay gone.
resource "appwrite_postgresql_branch" "ephemeral" {
  database_id = appwrite_postgresql_database.main.id
  branch_id   = "ci-run"
  ttl         = 3600
}

# Branches have no update route, so changing any argument replaces the branch
# and discards whatever was written to it.
output "preview_host" {
  value = appwrite_postgresql_branch.preview.host
}

output "preview_connection_string" {
  value     = appwrite_postgresql_branch.preview.connection_string
  sensitive = true
}
```

## Schema

### Required

- `database_id` (String) The dedicated database ID to branch from.

### Optional

- `branch_id` (String) The branch ID. Generated by the server when omitted.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.
- `ttl` (Number) How many seconds the branch lives before the server deletes it. Omit for a branch that persists until destroyed.

### Read-Only

- `branch_name` (String) The branch name.
- `connection_string` (String, Sensitive) The full connection URI for the branch, including credentials.
- `database` (String) The database name a client sends to be routed to this branch.
- `engine` (String) The database engine reported by the server.
- `expires_at` (Number) The Unix timestamp when the branch expires. 0 when it does not expire.
- `host` (String) The hostname to connect to the branch on.
- `id` (String) The branch identifier, in the form `database_id/branch_id`.
- `namespace` (String) The Kubernetes namespace the branch is deployed in.
- `password` (String, Sensitive) The password to connect with. Shared with the parent database.
- `port` (Number) The port to connect to the branch on.
- `ssl` (Boolean) Whether SSL is required for client connections.
- `username` (String) The username to connect with. Shared with the parent database.

## Import

Import is supported using the following syntax:

```shell
terraform import appwrite_postgresql_branch.preview <database-id>/<branch-id>
```
