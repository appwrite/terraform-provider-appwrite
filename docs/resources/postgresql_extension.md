# Resource: appwrite_postgresql_extension

Installs an extension into a dedicated Appwrite PostgreSQL database. Read the installable names from the `available` list of the corresponding extensions data source.

## Example Usage

```terraform
resource "appwrite_postgresql_database" "main" {
  name          = "main"
  specification = "db-s-1vcpu-1gb"
}

resource "appwrite_postgresql_extension" "postgis" {
  database_id = appwrite_postgresql_database.main.id
  name        = "postgis"
}

resource "appwrite_postgresql_extension" "pg_trgm" {
  database_id = appwrite_postgresql_database.main.id
  name        = "pg_trgm"
}

# The installable names come from the API, so a typo fails at apply rather than
# silently doing nothing.
data "appwrite_postgresql_extensions" "main" {
  database_id = appwrite_postgresql_database.main.id
}

output "available_extensions" {
  value = data.appwrite_postgresql_extensions.main.available
}
```

## Schema

### Required

- `database_id` (String) The dedicated database ID to install the extension into.
- `name` (String) The extension name, for example `postgis` or `pg_trgm`.

### Optional

- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.

### Read-Only

- `id` (String) The extension identifier, in the form `database_id/name`.

## Import

Import is supported using the following syntax:

```shell
terraform import appwrite_postgresql_extension.postgis <database-id>/postgis
```
