# Resource: appwrite_project_smtp

Manages a project's custom SMTP server, which Appwrite sends the project's emails through instead of its own.

Every project has exactly one SMTP configuration, so this resource takes it over rather than creating one. Only one `appwrite_project_smtp` should manage a given project.

A project API key with the `project.read` and `project.write` scopes is required.

~> **Note:** While `enabled` is true, Appwrite connects to the server and authenticates every time the configuration is saved, and rejects a configuration that fails with `project_smtp_config_invalid`. The server has to be reachable from Appwrite when you apply, not only when Appwrite sends email. With `enabled = false` the configuration is saved without connecting.

~> **Note:** Appwrite never returns the password, so a password changed outside Terraform is not detected. Use `password_wo` with `password_wo_version` to keep it out of state; leaving out both `password` and `password_wo` clears it.

~> **Note:** Once `secure` is set, Appwrite cannot remove it: the API accepts only `tls` and `ssl`. A plan that removes it fails, so it can be switched between the two but a project cannot go back to an unencrypted connection. The same applies when the project already had `secure` set before Terraform managed it.

~> **Note:** Destroying this resource disables custom SMTP and clears the username, password, sender and reply-to details. The host, port and `secure` stay, because the API cannot clear them, but Appwrite ignores them while custom SMTP is disabled. Appwrite then sends the project's emails through its own server, and stops using custom email templates.

To check that the configuration delivers mail, use **Send test email** in the Appwrite Console, or the `POST /v1/project/smtp/tests` endpoint.

## Example Usage

```terraform
variable "smtp_password" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "appwrite_project_smtp" "example" {
  host                = "smtp.example.com"
  port                = 587
  secure              = "tls"
  username            = "apikey"
  password_wo         = var.smtp_password
  password_wo_version = 1
  sender_email        = "noreply@example.com"
  sender_name         = "Example"
  reply_to_email      = "support@example.com"
}
```

## Schema

### Required

- `host` (String) The SMTP server's host name or IP address, without a scheme or port.
- `port` (Number) The SMTP server's port.
- `sender_email` (String) The email address emails are sent from.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `enabled` (Boolean) Whether Appwrite sends the project's emails through this server. While it is true, Appwrite connects to the server and authenticates whenever the configuration is saved, and rejects a configuration that fails. Defaults to true.
- `password` (String, Sensitive) The password to authenticate with. Stored in Terraform state; prefer password_wo, which is not. Appwrite never returns the password, so a change made outside Terraform is not detected. Leaving out both password and password_wo clears it.
- `password_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The password to authenticate with, as a write-only argument. Read from the configuration during apply and never persisted. Change password_wo_version to apply a new value, since Terraform cannot detect a change in a value it does not store. Requires Terraform 1.11 or later.
- `password_wo_version` (Number) Increment to apply a changed password_wo.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.
- `reply_to_email` (String) The email address replies go to.
- `reply_to_name` (String) The name replies go to.
- `secure` (String) The encryption to use: tls for STARTTLS, or ssl for implicit TLS. Without it, the connection is not encrypted. Appwrite cannot remove this setting once it is stored, so it can be changed between tls and ssl but not removed again.
- `sender_name` (String) The name emails are sent from.
- `username` (String) The username to authenticate with. Without one, Appwrite does not authenticate.

### Read-Only

- `id` (String) The ID of the project the SMTP configuration belongs to.

## Import

Import uses the project ID:

```shell
terraform import appwrite_project_smtp.example project-id
```

Using an import block (Terraform v1.5.0+):

```hcl
import {
  to = appwrite_project_smtp.example
  id = "project-id"
}
```

A project that has never had custom SMTP configured has nothing to import. The password is not imported, since Appwrite never returns it.
