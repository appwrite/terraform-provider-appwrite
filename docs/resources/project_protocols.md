# Resource: appwrite_project_protocols

Enables and disables the protocols a project's API is served over. Each protocol is managed only when its attribute is set. Disabling REST does not block requests made with an API key, including the provider's own; disabling GraphQL does.

Each attribute is optional, and a protocol whose attribute is left out is not managed: it keeps whatever setting it has, and a change made to it in the Console is not reported. Setting an attribute manages that protocol. Removing the attribute later enables the protocol again, which is Appwrite's default. Destroying the resource enables every protocol it manages and leaves the rest as they are.

Declare at most one of these per project. Two would overwrite each other's settings on every apply.

~> **Note:** Disabling `rest` turns away REST requests from users and guests. Requests made with an API key are let through, and so are Console users. The provider's own requests use a key, so Terraform keeps working with REST disabled.

!> **Warning:** Disabling `graphql` turns away every GraphQL request, including ones made with an API key. Server-side code that queries GraphQL with a key stops working.

A standard project API key with `project.read` and `project.write` scopes is required. Configure it with the provider's `api_key` attribute or `APPWRITE_API_KEY`.

## Example Usage

```terraform
# Serve the project over REST only. Protocols left out are not managed.
resource "appwrite_project_protocols" "example" {
  graphql   = false
  websocket = false
}
```

## Schema

### Optional

- `graphql` (Boolean) Whether the GraphQL API is enabled. Unlike `rest`, this applies to requests made with an API key too. Left unset, the protocol is not managed; removing the attribute from the configuration enables it again.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.
- `rest` (Boolean) Whether the REST API is enabled. Left unset, the protocol is not managed; removing the attribute from the configuration enables it again.
- `websocket` (Boolean) Whether Realtime over WebSocket is enabled. Left unset, the protocol is not managed; removing the attribute from the configuration enables it again.

### Read-Only

- `id` (String) The project ID.

## Import

Using `terraform import` with a project ID:

```shell
terraform import appwrite_project_protocols.example project-id
```

Using an import block (Terraform v1.5.0+):

```hcl
import {
  to = appwrite_project_protocols.example
  id = "project-id"
}
```

Importing records the setting of every protocol the project reports. If the configuration leaves a protocol out, the next plan removes it from state, and applying that plan enables the protocol.
