# Resource: appwrite_vectorsdb_document

Manages a document in an Appwrite VectorsDB collection.

This manages data rather than infrastructure, so it suits seed and reference records. Documents written by an application at runtime should not be managed here.

## Example Usage

```terraform
resource "appwrite_vectorsdb" "main" {
  name = "embeddings"
}

resource "appwrite_vectorsdb_collection" "articles" {
  database_id = appwrite_vectorsdb.main.id
  name        = "Article embeddings"
  dimension   = 4
}

# The embedding must carry exactly `dimension` values, four in this toy example.
# Real embeddings come from a model, so they are usually written by the
# application rather than pinned in configuration.
resource "appwrite_vectorsdb_document" "seed" {
  database_id   = appwrite_vectorsdb.main.id
  collection_id = appwrite_vectorsdb_collection.articles.id
  id            = "seed"

  data = jsonencode({
    embedding = [0.1, 0.2, 0.3, 0.4]
    source_id = "article-1"
  })
}
```

## Schema

### Required

- `collection_id` (String) The collection ID the document belongs to.
- `data` (String) The document body as a JSON object string, for example `jsonencode({ title = "Hello" })`. A VectorsDB document carries its embedding, which must have exactly the collection's `dimension` values. Only the keys present here are tracked, so fields written by other clients do not show as drift.
- `database_id` (String) The database ID.

### Optional

- `id` (String) The document ID. Generated when omitted.
- `permissions` (Set of String) The document permissions. Only enforced when the collection has `document_security` enabled.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.

### Read-Only

- `created_at` (String) The document creation timestamp in ISO 8601 format.
- `updated_at` (String) The document last update timestamp in ISO 8601 format.

## Import

Import is supported using the following syntax:

```shell
terraform import appwrite_vectorsdb_document.seed <database-id>/<collection-id>/<document-id>
```
