# appwrite_database_column (Resource)

Manages a column in an Appwrite table.

## Example Usage

```terraform
# Varchar column with max length
resource "appwrite_column" "name" {
  database_id = appwrite_database.main.id
  table_id    = appwrite_table.users.id
  key         = "name"
  type        = "varchar"
  size        = 255
  required    = true
}
```
