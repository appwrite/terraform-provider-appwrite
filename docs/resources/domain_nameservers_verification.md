# Resource: appwrite_domain_nameservers_verification

Waits for Appwrite to confirm that a domain is delegated to its nameservers. Appwrite only checks delegation when asked, so this asks until the check passes or the create timeout expires. It changes nothing at the registrar: point the domain at appwrite_domain.appwrite_nameservers first.

Appwrite records whether a domain is delegated to its nameservers when the domain is added, and afterwards only when a check is requested. A domain added before its registrar was updated therefore stays unverified until something asks again; in the Console that is the retry button, and in Terraform it is this resource. Creating it asks Appwrite to check every 30 seconds until the check passes, and fails when the create timeout expires, naming the nameservers the registrar should list.

The resource does not recheck later: refreshing it never changes anything, and destroying it only removes it from state. Make resources that need a delegated domain depend on it.

Domains are available on Appwrite Cloud. An organization API key with `domains.read` and `domains.write` scopes is required. Configure it with the provider's `organization_api_key` attribute or `APPWRITE_ORGANIZATION_API_KEY`. Set `organization_id` on the provider or on this resource.

-> Registrars usually publish a nameserver change within minutes, but resolvers can keep the previous delegation for up to 48 hours. The default create timeout is 30 minutes; raise it in a `timeouts` block when the change is recent.

## Example Usage

```terraform
resource "appwrite_domain" "example" {
  domain = "example.com"
}

# Set appwrite_domain.example.appwrite_nameservers at the domain's registrar,
# for example with that registrar's own Terraform provider, then wait for
# Appwrite to see the delegation.
resource "appwrite_domain_nameservers_verification" "example" {
  domain_id = appwrite_domain.example.id

  timeouts {
    create = "2h"
  }
}

# Records that only work once Appwrite serves the zone can wait for it.
resource "appwrite_domain_record" "www" {
  domain_id = appwrite_domain_nameservers_verification.example.id
  type      = "CNAME"
  name      = "www"
  value     = "example.appwrite.network"
}
```
