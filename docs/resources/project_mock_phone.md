# Resource: appwrite_project_mock_phone

Registers a mock phone number in a project. Signing in with a phone token for the number sends no SMS and accepts the fixed code set here, which lets test and app-review accounts sign in without a real phone.

A standard project API key with `mocks.read` and `mocks.write` scopes is required. Configure it with the provider's `api_key` attribute or `APPWRITE_API_KEY`.

~> **Warning:** Anyone who knows the number and its code can sign in as the user it belongs to. The code is stored in Terraform state; use an encrypted remote state backend and restrict access to it.

The [phone auth method](project_auth_methods.md) must be enabled for the number to be used to sign in.

## Example Usage

```terraform
# Lets an app store reviewer sign in with a phone number without receiving an SMS.
resource "appwrite_project_mock_phone" "app_review" {
  number = "+15555550100"
  otp    = "123456"
}
```

## Schema

### Required

- `number` (String) The phone number in E.164 format, such as `+15555550100`. Changing this forces a new resource to be created.
- `otp` (String, Sensitive) The six-digit code that signs in with this number.

### Optional

- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.

### Read-Only

- `created_at` (String) When the mock number was added.
- `id` (String) The phone number, the same as `number`.
- `updated_at` (String) When the mock number's code was last changed.

## Import

Using `terraform import` with a project ID and the number:

```shell
terraform import appwrite_project_mock_phone.app_review project-id/+15555550100
```

When `project_id` is configured on the provider, the number alone can be used.
