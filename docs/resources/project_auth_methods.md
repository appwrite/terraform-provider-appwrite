# Resource: appwrite_project_auth_methods

Enables or disables the ways users can sign in to a project. Requests made with an API key are not affected. Every project has these settings, so creating this resource takes them over rather than creating anything, and destroying it resets them to Appwrite's defaults. An attribute left out of the configuration is set to its default too. Use one per project: two would overwrite each other.

A standard project API key with `project.read` and `project.write` scopes is required. Configure it with the provider's `api_key` attribute or `APPWRITE_API_KEY`.

~> **Note:** Applying this resource sets every method: the ones in the configuration to their configured value, the rest to enabled. A method turned off in the Console is turned back on by the first apply unless the configuration turns it off too. Import the resource first to see the current settings in the plan.

Turning a method off only affects users signing in through the client APIs. Server-side requests made with an API key, such as creating a session through the Users API, are not checked against it.

OAuth2 providers are configured separately.

## Example Usage

```terraform
# Email and password sign-in, team invitations and JWTs only.
resource "appwrite_project_auth_methods" "example" {
  email_password = true
  invites        = true
  jwt            = true

  magic_url = false
  email_otp = false
  anonymous = false
  phone     = false
}
```

## Schema

### Optional

- `anonymous` (Boolean) Whether users can create anonymous sessions. Defaults to `true`.
- `email_otp` (Boolean) Whether users can sign in with a one-time code sent to their email address. Defaults to `true`.
- `email_password` (Boolean) Whether users can sign up and sign in with an email address and password. Defaults to `true`.
- `invites` (Boolean) Whether users can join the project by accepting a team invitation. Defaults to `true`.
- `jwt` (Boolean) Whether users can create JWTs for their session. Defaults to `true`.
- `magic_url` (Boolean) Whether users can sign in with a magic URL sent to their email address. Defaults to `true`.
- `phone` (Boolean) Whether users can sign in with a one-time code sent to their phone number by SMS. Defaults to `true`.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.

### Read-Only

- `id` (String) The project ID.

## Import

Using `terraform import` with a project ID:

```shell
terraform import appwrite_project_auth_methods.example project-id
```

Using an import block (Terraform v1.5.0+):

```hcl
import {
  to = appwrite_project_auth_methods.example
  id = "project-id"
}
```
