# Resource: appwrite_function

Manages an Appwrite function.

## Example Usage

```terraform
resource "appwrite_function" "hello_world" {
  name       = "hello-world"
  runtime    = "node-22"
  entrypoint = "index.js"
  commands   = "npm install"
}

resource "appwrite_function" "scheduled" {
  name     = "daily-cleanup"
  runtime  = "node-22"
  schedule = "0 0 * * *"
  timeout  = 60
}

resource "appwrite_function" "event_driven" {
  name       = "on-user-create"
  runtime    = "node-22"
  events     = ["users.*.create"]
  entrypoint = "index.js"
  execute    = ["any"]
}
```

## Schema

### Required

- `name` (String) The function name.
- `runtime` (String) The function execution runtime (e.g. node-22, python-3.11, dart-3.5).

### Optional

- `build_specification` (String) Machine specification for deployment builds.
- `commands` (String) The build command used to build the deployment.
- `deployment_retention` (Number) How many days to keep non-active deployments before automatic deletion.
- `enabled` (Boolean) Whether the function is enabled. Defaults to true.
- `entrypoint` (String) The entrypoint file used to execute the deployment.
- `events` (List of String) Events that trigger the function.
- `execute` (List of String) Execution permissions (e.g. users, teams, roles).
- `id` (String) The function ID.
- `installation_id` (String) VCS (Version Control System) installation ID.
- `logging` (Boolean) Whether execution logs are enabled. When disabled, executions will be slightly faster. Defaults to true.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.
- `provider_branch` (String) VCS (Version Control System) branch name.
- `provider_repository_id` (String) VCS (Version Control System) repository ID.
- `provider_root_directory` (String) Path to function in VCS repository.
- `provider_silent_mode` (Boolean) Whether VCS silent mode is enabled (no comments on pull requests).
- `runtime_specification` (String) Machine specification for executions.
- `schedule` (String) Function execution schedule in CRON format.
- `scopes` (List of String) Allowed permission scopes.
- `timeout` (Number) Function execution timeout in seconds. Defaults to 15.

### Read-Only

- `created_at` (String) The function creation timestamp in ISO 8601 format.
- `deployment_id` (String) The active deployment ID.
- `updated_at` (String) The function last update timestamp in ISO 8601 format.

## VCS Integration

Connect a function to a Git repository for automatic deployments on push:

```hcl
resource "appwrite_function" "api" {
  name    = "api"
  runtime = "node-22"

  installation_id         = "your-github-installation-id"
  provider_repository_id  = "your-repository-id"
  provider_branch         = "main"
  provider_root_directory = "functions/api"
}
```
