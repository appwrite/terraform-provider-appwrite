# Resource: appwrite_tablesdb_row

Manages a row in an Appwrite tablesdb table.

## Example Usage

```terraform
resource "appwrite_tablesdb" "main" {
  name = "main"
}

resource "appwrite_tablesdb_table" "users" {
  database_id = appwrite_tablesdb.main.id
  name        = "users"
}

resource "appwrite_tablesdb_column" "name" {
  database_id = appwrite_tablesdb.main.id
  table_id    = appwrite_tablesdb_table.users.id
  key         = "name"
  type        = "varchar"
  size        = 255
  required    = true
}

resource "appwrite_tablesdb_column" "email" {
  database_id = appwrite_tablesdb.main.id
  table_id    = appwrite_tablesdb_table.users.id
  key         = "email"
  type        = "email"
  required    = true
}

resource "appwrite_tablesdb_row" "alice" {
  database_id = appwrite_tablesdb.main.id
  table_id    = appwrite_tablesdb_table.users.id
  data = jsonencode({
    name  = "alice"
    email = "alice@example.com"
  })

  depends_on = [
    appwrite_tablesdb_column.name,
    appwrite_tablesdb_column.email,
  ]
}
```

## Schema

### Required

- `data` (String) The row data as a JSON object. Keys are column keys, values are column values.
- `database_id` (String) The database ID.
- `table_id` (String) The table ID.

### Optional

- `id` (String) The row ID.
- `permissions` (List of String) Row permissions.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.

### Read-Only

- `created_at` (String) The row creation timestamp in ISO 8601 format.
- `updated_at` (String) The row last update timestamp in ISO 8601 format.
