# Resource: appwrite_analytics_property

Manages an analytics property on an Appwrite Cloud project: one website, app or agent whose events the project collects.

Analytics is available on Appwrite Cloud only; self-hosted Appwrite does not serve its API. A standard project API key with `analytics.read` and `analytics.write` scopes is required. Configure it with the provider's `api_key` attribute or `APPWRITE_API_KEY`. Appwrite Cloud limits how many properties a project can hold, depending on its plan.

Sending an event needs no key: a client names the project and the property's `id`. `allowed_origins` limits which browser origins may send events, and anything other than `["*"]` also rejects requests that carry no `Origin` header unless they use a key with the `analytics.write` scope.

Changing `id` or `project_id` replaces the property, and with it every event collected for it. Every other argument is updated in place, and an optional argument removed from the configuration goes back to its default.

## Example Usage

```terraform
resource "appwrite_analytics_property" "website" {
  name            = "Website"
  domain          = "example.com"
  allowed_origins = ["https://example.com"]
}

resource "appwrite_analytics_property" "app" {
  id   = "app"
  name = "Mobile app"
  type = "mobile"
}
```

## Schema

### Required

- `name` (String) The property name.

### Optional

- `allowed_origins` (List of String) The origins allowed to send events. Defaults to `["*"]`, which allows all.
- `domain` (String) The primary domain to track, such as `example.com`. Mobile and agent properties can leave it empty. Defaults to empty.
- `enabled` (Boolean) Whether the property accepts events. Events sent to a disabled property are rejected as not found. Defaults to true.
- `id` (String) The property ID, which clients name when they send an event. Changing this forces a new resource to be created.
- `identify_users` (Boolean) Whether events sent from a client session record the signed-in user's ID, so traffic can be counted by user. Defaults to false.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id. Changing this forces a new resource to be created.
- `type` (String) The kind of product the property tracks: `web`, `mobile` or `agent`. It only changes which panels the console shows; every type accepts the same events. Defaults to `web`.

### Read-Only

- `created_at` (String) The property creation timestamp in ISO 8601 format.
- `updated_at` (String) The property last update timestamp in ISO 8601 format.

## Import

Using `terraform import` with a project and property ID:

```shell
terraform import appwrite_analytics_property.website project-id/website
```

When `project_id` is configured on the provider, the property ID alone can be used:

```shell
terraform import appwrite_analytics_property.website website
```

Using an import block (Terraform v1.5.0+):

```hcl
import {
  to = appwrite_analytics_property.website
  id = "project-id/website"
}
```
