# Resource: appwrite_postgresql_backup_policy

Manages a scheduled backup policy for a dedicated Appwrite PostgreSQL database. Use `appwrite_backup_policy` instead for databases running on Appwrite's shared infrastructure.

## Example Usage

```terraform
resource "appwrite_postgresql_database" "main" {
  name          = "main"
  specification = "s-1vcpu-1gb"
}

# A full snapshot every night, kept for a week.
resource "appwrite_postgresql_backup_policy" "nightly" {
  database_id = appwrite_postgresql_database.main.id
  name        = "nightly"
  schedule    = "0 3 * * *"
  retention   = 7
  type        = "full"
}

# Incremental backups every six hours narrow the recovery window without paying
# for a full snapshot each time.
resource "appwrite_postgresql_backup_policy" "incremental" {
  database_id = appwrite_postgresql_database.main.id
  name        = "six-hourly"
  schedule    = "0 */6 * * *"
  retention   = 3
  type        = "incremental"
}
```

## Schema

### Required

- `database_id` (String) The dedicated database ID the policy backs up.
- `name` (String) The backup policy name.
- `retention` (Number) How many days to keep each backup before it is deleted automatically.
- `schedule` (String) The backup schedule in CRON format, for example `0 3 * * *` for daily at 03:00 UTC.

### Optional

- `enabled` (Boolean) Whether the policy is enabled. Defaults to true.
- `id` (String) The backup policy ID. Must be unique within the database. Generated when omitted.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.
- `type` (String) The backup type. `full` takes a complete snapshot; `incremental` stores changes since the last backup. Changing this replaces the policy.

### Read-Only

- `created_at` (String) The policy creation timestamp in ISO 8601 format.
- `resource_id` (String) The single resource the policy backs up, when scoped to one.
- `resource_type` (String) The type of the single resource the policy backs up.
- `resources` (Set of String) The resources covered by this policy.
- `services` (Set of String) The services covered by this policy.
- `updated_at` (String) The policy last update timestamp in ISO 8601 format.

## Import

Import is supported using the following syntax:

```shell
terraform import appwrite_postgresql_backup_policy.nightly <database-id>/<policy-id>
```
