# Resource: appwrite_documentsdb_collection

Manages a collection in an Appwrite DocumentsDB database. A DocumentsDB collection stores schemaless JSON documents.

## Example Usage

```terraform
resource "appwrite_documentsdb" "main" {
  name = "main"
}

resource "appwrite_documentsdb_collection" "articles" {
  database_id = appwrite_documentsdb.main.id
  id          = "articles"
  name        = "Articles"

  # Collection-level permissions. Enable document_security as well to have
  # per-document permissions enforced on top of these.
  permissions       = ["read(\"any\")", "create(\"users\")"]
  document_security = true
}
```

## Schema

### Required

- `database_id` (String) The database ID the collection belongs to.
- `name` (String) The collection name.

### Optional

- `document_security` (Boolean) Whether document-level permissions are enforced in addition to collection-level ones.
- `enabled` (Boolean) Whether the collection is enabled. When disabled it is inaccessible to users but still reachable with an API key. Defaults to true.
- `id` (String) The collection ID. Must be unique within the database. Generated when omitted.
- `permissions` (Set of String) The collection permissions, for example `read("any")` or `write("users")`.
- `project_id` (String) The Appwrite project ID. Defaults to the provider-level project_id.

### Read-Only

- `dimension` (Number) Not applicable to DocumentsDB collections; always 0. Present only so both products share one state shape.
- `updated_at` (String) The collection last update timestamp in ISO 8601 format.
