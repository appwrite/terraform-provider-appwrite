# Appwrite Provider

The Appwrite provider is used to manage resources on [Appwrite](https://appwrite.io). It supports both Appwrite Cloud and self-hosted Community Edition instances.

## Authentication

~> **NOTE:** Avoid hard-coding credentials in your Terraform configuration. Use environment variables or a secrets manager instead.

Credentials can be supplied through environment variables or the provider configuration. Explicit provider values take precedence when both are set.

### Environment Variables (Recommended)

```shell
export APPWRITE_ENDPOINT="https://cloud.appwrite.io/v1"
export APPWRITE_PROJECT_ID="project-id"
export APPWRITE_ORGANIZATION_ID="organization-id"
export APPWRITE_API_KEY="project-api-key"
export APPWRITE_ORGANIZATION_API_KEY="organization-api-key"
```

### Provider Configuration

```terraform
provider "appwrite" {
  endpoint             = "https://cloud.appwrite.io/v1"
  project_id           = "project-id"
  organization_id      = "organization-id"
  api_key              = "project-api-key"
  organization_api_key = "organization-api-key"
}
```

### Credential Precedence

1. Values set directly in the provider configuration block
2. Environment variables (`APPWRITE_ENDPOINT`, `APPWRITE_PROJECT_ID`, `APPWRITE_ORGANIZATION_ID`, `APPWRITE_API_KEY`, `APPWRITE_ORGANIZATION_API_KEY`)

## Resource Scoping

The `project_id` can be set at the provider level as a default for project-scoped resources, or overridden per-resource. The `organization_id` works the same way for organization-scoped resources such as `appwrite_project`.

Use a standard project key in `api_key` for project resources and an organization key in `organization_api_key` for project and project-key administration. When `organization_api_key` is omitted, it falls back to `api_key` for backwards compatibility. The provider detects modern key prefixes and reports an actionable error when a resource receives an incompatible credential; legacy unprefixed keys are validated by Appwrite.

## Schema

### Optional

- `api_key` (String, Sensitive) The project API key used for project-scoped resources. Can also be set with the APPWRITE_API_KEY environment variable.
- `endpoint` (String) The Appwrite API endpoint (e.g. https://cloud.appwrite.io/v1). Can also be set with the APPWRITE_ENDPOINT environment variable.
- `organization_api_key` (String, Sensitive) The organization API key used for organization-scoped resources and project API key management. Defaults to api_key for backwards compatibility. Can also be set with the APPWRITE_ORGANIZATION_API_KEY environment variable.
- `organization_id` (String) The default Appwrite organization ID for organization-scoped resources. Can also be set with the APPWRITE_ORGANIZATION_ID environment variable. Can be overridden per-resource.
- `project_id` (String) The default Appwrite project ID for all resources. Can also be set with the APPWRITE_PROJECT_ID environment variable. Can be overridden per-resource.
- `self_signed` (Boolean) Accept self-signed SSL certificates. Useful for Appwrite Community Edition with self-signed certs. Defaults to false.

## Compatibility

TablesDB resources are intended for Appwrite Cloud or Appwrite Community Edition 1.9.0 and later. Earlier self-hosted versions may return `general_route_not_found` errors for TablesDB routes.
