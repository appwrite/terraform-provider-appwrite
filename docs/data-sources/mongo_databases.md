# Data Source: appwrite_mongo_databases

Lists the dedicated Appwrite MongoDB databases in a project. Connection credentials are deliberately not included; read them from the singular `appwrite_mongo_database` data source for the one database that needs them, so a listing does not put every password into state.

## Example Usage

```terraform
data "appwrite_mongo_databases" "all" {}

data "appwrite_mongo_databases" "ready" {
  queries = ["equal(\"status\", \"ready\")"]
}

output "database_names" {
  value = [for d in data.appwrite_mongo_databases.all.databases : d.name]
}
```
