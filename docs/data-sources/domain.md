# Data Source: appwrite_domain

Fetches a domain in an Appwrite organization by ID or by name. Use it to manage the DNS records of a domain that Terraform does not own, such as one bought through the Console.

Domains are available on Appwrite Cloud. An organization API key with the `domains.read` scope is required. Configure it with the provider's `organization_api_key` attribute or `APPWRITE_ORGANIZATION_API_KEY`. Set `organization_id` on the provider or on this data source.

## Example Usage

```terraform
data "appwrite_domain" "example" {
  domain = "example.com"
}

resource "appwrite_domain_record" "www" {
  domain_id = data.appwrite_domain.example.id
  type      = "CNAME"
  name      = "www"
  value     = "example.appwrite.network"
}
```

## Schema

### Optional

- `domain` (String) The domain name, such as example.com. Exactly one of id or domain must be set.
- `id` (String) The domain ID. Exactly one of id or domain must be set.
- `organization_id` (String) The Appwrite organization ID. Defaults to the provider-level organization_id.

### Read-Only

- `appwrite_nameservers` (List of String) The nameservers Appwrite serves this domain's zone from.
- `auto_renewal` (Boolean) Whether a domain registered through Appwrite renews automatically.
- `created_at` (String) The domain creation timestamp in ISO 8601 format.
- `expires_at` (String) When a domain registered through Appwrite expires, in ISO 8601 format. Empty for a domain registered elsewhere.
- `nameservers_verified` (Boolean) Whether Appwrite found the domain delegated to its nameservers when it last checked.
- `registrar` (String) Who the domain is registered through: appwrite for a domain bought or transferred through Appwrite. Any other value, including an empty one, means it is registered elsewhere.
- `updated_at` (String) The domain last update timestamp in ISO 8601 format.
