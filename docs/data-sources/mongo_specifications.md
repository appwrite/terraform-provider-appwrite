# Data Source: appwrite_mongo_specifications

Lists the compute specifications available for dedicated MongoDB databases, so a `specification` slug can be selected without hardcoding it. Availability depends on the organization's billing plan; check `enabled` before using a slug.

## Example Usage

```terraform
data "appwrite_mongo_specifications" "available" {}

output "available_specifications" {
  value = [for s in data.appwrite_mongo_specifications.available.specifications : s.slug if s.enabled]
}
```
